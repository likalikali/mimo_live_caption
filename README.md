# 多模型实时字幕 0.9.2

Windows 实时字幕程序，支持麦克风与 WASAPI Loopback 电脑声音、本地逐词字幕、MiMo/SiliconFlow 云端校正，以及 Google/OpenAI 兼容翻译。

## 0.9.2 重点变化

### 1. 默认隐藏时间戳与音源标签

字幕默认不再显示：

```text
20:47:11 [会议]
```

而是直接显示正文。麦克风和电脑声音使用不同文字颜色：

- 麦克风默认绿色 `#75d69c`
- 电脑声音默认蓝色 `#7fc8ff`

可以在“设置 → 转录与音频”中重新打开时间戳或 `[我]/[会议]`，也可以填写任意 `#RRGGBB` 颜色。

当前程序只能直接知道两个音频来源：麦克风与电脑回放。电脑回放中的多位远端参会者仍属于同一个音源；要让每位远端说话人拥有独立颜色，需要另行加入说话人分离/聚类模块。

### 2. 更准确的本地双语流式模型

新增推荐模型：

```text
sherpa-onnx-streaming-paraformer-bilingual-zh-en
```

它支持普通话与英语实时识别，并比旧的“小型双语 Zipformer”占用更多内存。程序仍兼容旧模型；安装了新模型后会优先使用新模型。

运行：

```text
install_streaming_model.bat
```

默认通过：

```text
http://127.0.0.1:20800
```

下载“accurate”模型到当前项目目录：

```text
项目目录\models\sherpa-onnx-streaming-paraformer-bilingual-zh-en
```

手动指定：

```bat
install_streaming_model.bat http://127.0.0.1:20800 accurate
install_streaming_model.bat socks5h://127.0.0.1:20800 fast
```

`accurate` 是较高准确率 Paraformer；`fast` 是原来的低资源小模型。

### 3. 英文临时字幕不再全大写

部分旧流式模型的词表会输出全大写英文。0.9.2 只对“本地未定稿字幕”做显示层大小写恢复，例如：

```text
LAB IS CALLED MOON SHOOT A
```

显示为：

```text
Lab is called moon shoot a
```

常见缩写如 `AI`、`API`、`GPU`、`OpenAI` 会尽量保留。MiMo/SiliconFlow 返回的云端定稿文字不会被这项规则改写。

### 4. 分别设置麦克风与电脑声音的句末停顿

视频、会议和访谈中，讲话人经常在一句话中间停顿。旧版本用同一个 600 毫秒阈值，容易把一句话切成两段，导致类似：

```text
从国内字节转
转来东京字节已经快一年
```

0.9.2 默认：

```text
麦克风句末停顿：650 毫秒
电脑声音句末停顿：1100 毫秒
麦克风最长语音段：15 秒
电脑声音最长语音段：25 秒
```

电脑声音会等待更长停顿再定稿，更接近完整句子。连续讲话达到最长时长才强制切分，并保留约 900 毫秒音频上下文；相邻云端结果还会进行忽略标点和空格的边界去重。

### 5. 云端校正默认不再流式返回

逐词显示已经由本地模型负责。MiMo 的云端任务现在默认只在一句话结束后请求一次普通响应，减少“流式响应结束但没有正文”的失败情况，也避免临时云端结果反复覆盖本地字幕。

需要时仍可在设置中开启“云端校正使用流式返回”，但通常建议关闭。

## 推荐设置

```text
启用本地逐词实时字幕：开启
本地流式模型：项目目录\models\sherpa-onnx-streaming-paraformer-bilingual-zh-en
本地解码线程：2～4
VAD 灵敏度：2
麦克风句末停顿：650 毫秒
电脑声音句末停顿：1100～1300 毫秒
麦克风最长语音段：15 秒
电脑声音最长语音段：25 秒
云端校正流式返回：关闭
实时翻译预览：关闭
```

电脑视频仍被错误切断时，可以把“电脑声音句末停顿”提高到 1300 或 1600 毫秒；代价是云端定稿与翻译会稍晚出现，本地逐词字幕不受影响。

## 两阶段字幕架构

1. 本地 sherpa-onnx 持续接收 PCM，产生低延迟临时字幕。
2. 检测到句末停顿后，仅向 MiMo 或 SiliconFlow 提交一次完整语音段。
3. 云端结果替换同一字幕块中的本地文字。
4. 定稿后调用一次 Google 或大模型翻译。

每条字幕拥有独立 ID 和 `QTextBlock`。原文、译文与后续字幕不会共享漂移的文本游标，因此新字幕不会覆盖前一条译文。

## 安装

1. 解压项目。
2. 双击 `run.bat` 创建虚拟环境并安装依赖。
3. 双击 `install_streaming_model.bat` 下载推荐模型。
4. 重启程序；如果新模型已完整安装，程序会自动优先选择它。

## 隐私

本地临时字幕完全离线。停顿后的完整语音段会发送给你配置的 MiMo 或 SiliconFlow；定稿文字会发送给你配置的翻译服务。
